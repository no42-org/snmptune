# Support

- **Questions and usage help**: open a [GitHub issue](https://github.com/no42-org/snmptune/issues/new/choose) with the question template. Include the command you ran and the report it printed.
- **Bugs**: use the bug template and attach the PDU log from `--pdu-log` where it helps. Redact community strings.
- **Security problems**: never a public issue. See `SECURITY.md`.

There is no commercial support and no guaranteed response time. Issues are usually answered within a week.
