# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussions about the work. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour to ronny@no42.org. Reports are handled confidentially, and the maintainer will respond within a week.

Enforcement follows the Contributor Covenant's guidelines: a private warning for a first incident, a temporary ban for repeated or serious incidents, and a permanent ban for sustained or egregious behaviour.
